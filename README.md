# GharFix — Home Services (demo)

Fictional demo website for a Pakistani home-services business: book verified
plumbers, electricians, AC technicians, deep cleaners and painters in 60 seconds.

- Next.js 16 + TypeScript + Tailwind CSS 4
- Cinematic AI-generated video hero (`public/hero.mp4`)
- AI-generated service photos in `public/service-*.webp` (no external image URLs)
- 60-second booking form builds a WhatsApp message link (placeholder number)
- No environment variables required — deploys on Vercel as-is

```bash
npm install
npm run dev
npm run build
```
